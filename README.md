# 🎮 Mario Pro2

A Mario-style platformer built in C++ for the PRO2 course at UPC-FIB.

You run, jump, and collect coins across an endless procedurally generated level. The project was built incrementally across three mods, each adding a new feature on top of the previous one.


## The Mods

**Mod 1 — Coin Collection**
Coins bob up and down using a sine function and disappear when Mario touches them. Includes sprite rendering, hitbox collision, and score tracking.

**Mod 2 — Visibility Culling**
A spatial grid (`Finder<T>`) maps objects to grid cells so only the ones near the camera are ever updated or drawn. With 500k platforms and 1.5M coins the game still runs smoothly.

**Mod 3 — Personal Ending**
Each student implements their own feature to finish the game however they want.
